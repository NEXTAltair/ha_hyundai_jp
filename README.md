# Hyundai Bluelink Japan

日本向け Hyundai Bluelink のアカウントから、車両の状態を Home Assistant に取り込むカスタム統合です。
状態を読むだけで、施錠や空調などの遠隔操作はしません。

実車で確認しているのは日本版 IONIQ 5 だけです。

## インストール

HACS の「カスタムリポジトリ」にこのリポジトリを「Integration」として追加し、インストールします。
Home Assistant を再起動したら、「設定 > デバイスとサービス > 統合を追加」から「Hyundai Bluelink Japan」を選び、
日本版 Hyundai Bluelink アプリで使っているメールアドレスとパスワードを入力します。

## 取り込む値

- 駆動用バッテリー、補機バッテリー、航続可能距離、走行距離、充電の残り時間
- ドアロック、各ドア、ボンネット、トランク、走行可能、タイヤ空気圧、充電、充電コネクター
- 位置
- 車両の最終同期（車がクラウドへ状態を上げた時刻）と最終取得（Home Assistant が取得に成功した時刻）

Home Assistant は10分ごとに、サーバーに残っている最新の状態を読みます。車を起こして状態を取り直すことはしないので、
値が変わるのは車がクラウドへ状態を上げたときだけです。取得に失敗したときは、古い値を出さずに「利用不可」にします。

## 接続障害の履歴

「接続障害の履歴」センサーの属性に、直近20件の障害と復旧を表示します。診断ファイルには最大200件を保存します。
同じ障害の連続した失敗は１件にまとめ、最初に検出した時刻、最後に失敗した時刻、復旧した時刻と原因の分類を記録します。
Home Assistant が停止している間は検出できません。過去の障害は、この機能を入れる前にはさかのぼれません。
パスワード、トークン、メールアドレス、車両 ID やサーバーの応答本文は履歴に保存しません。

ログイン時に公式画面がパスワード変更を案内した場合、統合は公式画面と同じ方法で１回スキップします。
スキップできないときは公式画面で確認し、再認証してください。

## 診断ファイル

診断ファイルでは、メールアドレス、パスワード、トークン、車両や端末の識別子、位置を伏せます。
共有する前に中身を確認してください。
